# 01. 제품

## 목표

회의가 끝나면 정리도 끝나 있게 한다.
"그때 뭐라고 했더라"가 사라지게 한다.

## 페르소나

- 주 3회 이상 회의에 들어가는 실무자
- 30~50대
- 개발자가 아니다

## MVP 범위

| # | 기능 | 내용 |
|---|---|---|
| 1 | 회의 내용 넣기 | 녹취 파일 업로드(mp3 · wav, 25MB 이하) 또는 메모 붙여넣기 |
| 2 | 세 갈래 정리 | 받아쓴 본문을 요약 / 결정사항 / 할 일로 나눈다 |
| 3 | 회의록 CRUD | 추가 · 목록 · 수정 · 삭제 4종 모두 화면에서 한다 |
| 4 | 검색 | 제목 · 참석자 · 날짜로 찾는다 |
| 5 | 할 일 모아 보기 | 할 일만 모은 화면. 담당자와 기한을 함께 보여 준다 |
| 6 | 테마 | 라이트 / 다크 토글. 고른 값은 `localStorage` 에 기억한다 |
| 7 | 모바일 | 360px 폭에서도 쓸 수 있게 반응형으로 만든다 |
