# 03. 설계

## 기술 결정

| 선택 | 대안 | 근거 | 트레이드오프 |
|---|---|---|---|
| 1) 백엔드 - FastAPI | Django, Express | Python 타입 힌트와 Pydantic 으로 요청 검증 · 오류 코드(400 · 422)를 한곳에서 다룬다. API 7개 규모에 맞게 가볍고, 문서(`/docs`)가 자동으로 나온다 | 관리자 화면 · 인증 같은 기본 제공 기능이 Django 보다 적어 확장 단계(JWT 로그인 등)에서 직접 붙여야 한다 |
| 2) 프론트 - Vanilla JS + Tailwind CDN. 백엔드가 같은 오리진에서 제공하고 `file://` 로 직접 열지 않는다 | React, Vue | 화면 4개 규모라 빌드 도구 없이 `index.html` · `app.js` 2개로 충분하다. 같은 오리진이라 CORS 설정이 필요 없다 | 화면이 늘면 DOM 갱신 코드가 길어진다. 컴포넌트 재사용 · 생태계 도움을 받지 못한다 |
| 3) DB - SQLite (SQLAlchemy ORM, 추후 PostgreSQL 전환 고려) | PostgreSQL 즉시 도입 | 파일 하나라 설치 · 운영 부담이 없다. ORM 을 거치므로 나중에 PostgreSQL 로 옮길 때 고칠 곳이 적다 | 동시 쓰기에 약하다. 팀 공유처럼 여러 사람이 함께 쓰면 전환이 필요하다 |
| 4) CSS - Tailwind 만. styled-components 금지 | styled-components, 직접 작성한 CSS 파일 | 클래스만으로 macOS 톤(둥근 모서리 · 그림자 · 반투명)과 반응형(360px)을 맞춘다. CDN 이라 빌드가 필요 없다 | HTML 클래스가 길어진다. CDN 방식은 사용하지 않는 클래스를 걸러내지 못해 첫 로딩이 무겁다 |
| 5) 받아쓰기 - Gemini API (`gemini-3.1-flash-lite`). 키는 `.env` 로만 읽고 저장소에 올리지 않는다 | Whisper 자체 구동, 브라우저 음성 인식 | 받아쓰기와 세 갈래 구분을 한 API 로 처리한다. 서버에 GPU · 모델 설치가 필요 없다 | 외부 호출이라 비용 · 요청 한도(429) · 장애(503)의 영향을 받는다. 녹취가 외부로 나간다 |
| 6) 상태관리 - 모듈 변수 + DOM 직접 갱신 | 상태관리 라이브러리(Redux 등), 프레임워크 상태 | 상태가 「현재 목록 · 열린 회의록 · 테마」 정도라 `app.js` 모듈 변수로 충분하다. 의존성이 늘지 않는다 | 상태와 화면이 어긋나지 않게 갱신 함수를 직접 챙겨야 한다. 규모가 커지면 다루기 어렵다 |
| 7) 디자인 시스템 - Mac OS UI 톤 | Material, Ant | 개발자가 아닌 실무자에게 익숙하고 차분한 화면을 준다. Tailwind 클래스로 따로 라이브러리 없이 만든다 | 정해진 컴포넌트 묶음이 없어 버튼 · 입력칸 스타일을 직접 일관되게 맞춰야 한다 |
| 8) 테마 - 라이트/다크 토글, `localStorage`, 초기값은 시스템 설정 | 라이트 고정, 테마 값을 서버에 저장 | 처음엔 OS 설정(`prefers-color-scheme`)을 따르고, 사용자가 고르면 브라우저에 기억한다. 로그인 없이 된다 | 기기 · 브라우저마다 설정이 따로 남는다. 모든 화면 요소에 다크용 색을 함께 정해야 한다 |

## 화면

### 배치

화면 배치는 [`docs/화면구성.pdf`](화면구성.pdf) 를 따른다. 여기에 옮겨 적지 않는다.

### 요소 이름

`docs/화면구성.pdf` 5쪽 id 표를 그대로 옮긴다.

| 요소 | id | 자리 |
|---|---|---|
| 검색 입력 | `q` · `from` · `to` | 목록 화면 상단 |
| 목록 칸 | `cards` | 카드 배치 구역 |
| 넣기 폼 | `title` · `metAt` · `attendees` | 제목 · 일시 · 참석자 |
| 파일 · 본문 | `file` · `body` | 녹취 파일과 받아쓴 본문 |
| 버튼 | `btnUp` · `btnSave` | 받아쓰기 · 정리 |
| 결과 세 칸 | `result` | 요약 · 결정사항 · 할 일 |
| 상세 창 | `modal` | 카드를 누르면 뜨는 겹침 창 |
| 제목 수정칸 | `mTitle` | 상세 창 안에서 제목을 고치는 칸 |
| 할 일 표 | `todoBody` | 표의 본문 행 |

- 한 번 정하면 바꾸지 않는다. 바꿔야 하면 **이 문서에 사유를 먼저 적는다**

## 의존성 추가 정책

**이 문서에 사유를 적기 전에는 새 의존성을 들이지 않는다.**

사전 승인 목록:

- `fastapi` - 백엔드 웹 프레임워크 (API 7개)
- `uvicorn` - FastAPI 를 띄우는 ASGI 서버
- `sqlalchemy` - SQLite ORM. 추후 PostgreSQL 전환 대비
- `pytest` - 테스트
- `httpx` - 테스트에서 FastAPI `TestClient` 가 쓰는 HTTP 클라이언트
- `google-genai` - Gemini API 호출 (받아쓰기 · 세 갈래 구분)
- `python-multipart` - `POST /api/upload` 의 파일 업로드(multipart) 처리
- `python-dotenv` - `.env` 에서 API 키 읽기
